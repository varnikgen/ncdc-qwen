## 📞 NCDC (Network Configuration & Device Control)
Современная система автопровижининга и управления IP-телефонами Yealink.

NCDC — это легковесный, контейнеризированный веб-сервис с удобным графическим интерфейсом, предназначенный для централизованного управления конфигурациями телефонов Yealink. Система поддерживает иерархическую генерацию конфигов, безопасный HTTPS-провижининг, 802.1x аутентификацию и push-уведомления (AutoP).

### ✨ Возможности
* 🌐 Веб-интерфейс: Современный UI на базе Bootstrap 5 и HTMX (без перезагрузки страниц).
* 📂 Иерархический провижининг: Глобальные настройки → Настройки модели → Индивидуальные настройки устройства.
* 🔒 Безопасность: Поддержка HTTPS, 802.1x (EAP-TLS / EAP-MD5) с загрузкой сертификатов.
* 📱 Управление DSS-клавишами: Гибкая настройка (BLF, Speed Dial, Account, N/A) с наследованием от аккаунта или индивидуальным переопределением.
* 🚀 AutoP Push: Мгновенное применение настроек на телефоне через HTTPS с базовой авторизацией.
* 📊 Audit Log: Полный журнал действий с автоматической очисткой старых записей (по умолчанию 90 дней).
* 🐳 Контейнеризация: Готов к развертыванию через Podman / Docker Compose.
### 🛠️ Технологический стек
* Backend: Python 3.11, FastAPI, SQLAlchemy, Uvicorn
* Frontend: Jinja2, HTMX, Bootstrap 5, Vanilla JS
* База данных: SQLite (легковесная, не требует отдельного сервера)
* Reverse Proxy: Nginx (в составе docker-compose)
* Инфраструктура: Podman / Docker
### 📋 Предварительные требования
* Установленный Podman (или Docker) и podman-compose.
* Доступ к TFTP/HTTPS серверу для раздачи прошивок и сертификатов (опционально, но рекомендуется).
* Доменное имя или IP-адрес, доступный телефонам (например, ncdc-dev.bsmuk.ru).
### 🚀 Установка и запуск
1. Склонируйте репозиторий:
```bash
   git clone <your-repo-url>
   cd ncdc-qwen
```
2. Убедитесь, что файл .dockerignore существует (чтобы избежать ошибок прав доступа при сборке):
```text
venv/
.venv/
__pycache__/
.git/
data/
*.log
```
3. Запустите сервисы:
```bash
podman-compose up --build -d
```
*Флаг --build обязателен при первом запуске или после добавления новых файлов.*
4. Проверьте статус:
```bash
podman-compose ps
podman logs ncdc-app
```
Вы должны увидеть сообщение: 
> INFO: Запущена фоновая задача очистки логов аудита (хранение: 90 дней).

### ⚙️ Первичная настройка
1. Откройте веб-интерфейс: ``https://ncdc-dev.bsmuk.ru``
2. Перейдите в Global Config и задайте базовые параметры:
	* static.auto_provision.server.url: https://ncdc-dev.bsmuk.ru/provision/
	* static.network.ip_address_mode: 0 (IPv4 Only)
	* local_time.time_zone: +10 (или ваш часовой пояс)
	* features.action_uri_limit_ip: IP-адрес вашего сервера NCDC.
3. Перейдите в Model Config и настройте модель (например, T46U):
	* Укажите URL прошивки (firmware.url).
	* Настройте 802.1x (Mode 0 для EAP-TLS с сертификатами).
4. Создайте SIP-аккаунты в разделе Account List.
5. Добавьте телефоны в Device List или дождитесь их автоматического обнаружения через Action URI.

### 🔍 Устранение неполадок (Troubleshooting)
#### 1. Телефон теряет сеть после провижининга (переключается на IPv6)
Причина: В глобальных настройках указан неверный режим IP.
Решение: Убедитесь, что в БД или через UI параметр ```static.network.ip_address_mode``` равен ```0``` (IPv4), а не ```1``` (IPv6).
#### 2. AutoP Push не работает (ошибка в логах)
Причина: Телефон требует HTTPS и авторизацию, а в БД не указаны учетные данные.
Решение: Убедитесь, что в таблице phones для устройства заполнены поля ```admin_username```и ```admin_password```, а также корректно указан ```ip_address``` и ```status = 'online'```.
#### 3. DSS-клавиши не применяются или отображаются некорректно
Причина: Конфликт наследования или отсутствие кавычек в шаблоне.
Решение:
 * В форме телефона поставьте галочку "Override DSS Keys", если хотите задать их вручную.
 * Убедитесь, что для типа N/A (type=0) генерируется linekey.X.enable = 0.
#### 4. Ошибка permission denied при сборке образа (podman-compose up --build)
Причина: Docker/Podman пытается скопировать локальную папку venv с символическими ссылками Windows/WSL.
Решение: Убедитесь, что файл .dockerignore существует в корне проекта и содержит строку venv/.
### 🔄 Резервное копирование
Поскольку используется SQLite, резервное копирование сводится к копированию файла базы данных и папки с шаблонами (если они менялись):
```bash
# Создать бэкап БД
cp data/ncdc.db backups/ncdc_$(date +%Y%m%d).db

# Восстановить БД
cp backups/ncdc_20231025.db data/ncdc.db
podman-compose restart ncdc-app
```
